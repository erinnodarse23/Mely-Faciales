# Mely Faciales

[![Sprint 0](https://img.shields.io/badge/Sprint-0-ff69b4)](https://github.com/erinnodarse23/Mely-Faciales) [![Estado: Documentación](https://img.shields.io/badge/estado-documentaci%C3%B3n-blue)](https://github.com/erinnodarse23/Mely-Faciales) [![UML](https://img.shields.io/badge/modelado-UML-green)](https://github.com/erinnodarse23/Mely-Faciales)

Web publicitaria para **Mely Faciales**: catálogo de tratamientos faciales con micro-videos, muro de reseñas de clientas, galería visual y contacto directo por WhatsApp. Sin sistema de citas: las citas se gestionan manualmente por WhatsApp.

## Stack previsto

- Frontend: React + TypeScript + Vite + Tailwind CSS (tema único rosa/skincare).
- Backend y datos: Firebase Authentication, Cloud Firestore y Firebase Storage.
- Despliegue: Firebase Hosting.
- Pruebas: Vitest + React Testing Library.
